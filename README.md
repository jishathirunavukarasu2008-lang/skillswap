# SkillSwap

## Resilient Peer-to-Peer Skill Exchange & Collaborative Learning Platform

SkillSwap is a Java web application that allows students to teach and learn skills from each other without monetary payment.

## Features

- User Registration and Login
- My Skills
- Skill Exchange
- Exchange Requests
- Learning Sessions
- SkillSwap Rescue
- SkillSwap Circles
- Smart Partner Recommendations
- Learning Progress Analytics
- Verified Skill Portfolio

## Technology Stack

- Java 17
- Jakarta Servlets
- JSP
- JDBC
- MySQL
- HTML
- CSS
- Apache Tomcat 10.1
- Maven
- Git and GitHub

## Architecture

User -> JSP -> Servlet -> DAO -> JDBC -> MySQL
